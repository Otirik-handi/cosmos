# 工程标准

`docs/standards/` 保存跨功能域的工程与仓库协作流程。产品需求、架构决定和当前实现行为分别由 [`requirements/`](../requirements/)、[`architecture/`](../architecture/)、[`adr/`](../adr/) 和 [`spec/`](../spec/) 负责。

- [`repository-workflow.md`](repository-workflow.md)：Issue、Proposal、Task、实现、验证、PR 与外部操作的衔接流程。

开发 Agent 的长期规则位于根 [`AGENTS.md`](../../AGENTS.md)，外部贡献流程位于 [`CONTRIBUTING.md`](../../CONTRIBUTING.md) 与 [`CONTRIBUTING.en.md`](../../CONTRIBUTING.en.md)。标准只在这里维护正文，其它入口使用触发式链接。
